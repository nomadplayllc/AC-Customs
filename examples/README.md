# Examples

No texture pack is bundled in the initial public-source package.

The development archive contained `DarkMode_v1.acui`, but it has been held back until the redistribution rights/provenance of every included texture payload are confirmed. This avoids accidentally publishing game-derived artwork under the source-code license.

A future example pack should use original project-owned artwork or clearly redistributable assets and should state its asset license separately from the AC Customs source-code license.
